# Вне уровня
* При старте должна показываться заставка
* После заставки должен появляться навигатор уровня
## Заставка
* На заставке должна быть картинка
* На заставке должен быть прогресс по загрузке игры (возмножно, если будем долго грузиться)
* На заставке должна быть указана текущая версия игры
## Навигатор
* В навигаторе должна быть картинка - подложка
* В навигаторе должно отображаться текущее состояние бонусов игрока

# Уровень
## Старт уровня
* При старте уровня должен быть прогресс  (возмножно, если будем долго грузиться)
* При старте уровня должны предлагаться выбираться бонусы из тех что у игрока есть
## Начальная конфигурация уровня
* Начальная конфигурация должна включать:
  * контур уровня: уровень может иметь сложный внешний контур и дырки в середине
  * описание направления перехода кубиков при исчезновении кубиков (каждая позиция известно куда переходит)
  * переход может быть в любую несвязанную точку
  * набор кубиков (набор цветов кубиков для изначального заполнения сверху)
  * расположение специальных кубиков изначальное

# Игровые предметы

## Игровые предметы (камни в общем виде)

### Камни

#### Виды
- Камни 5-ти различных цветов.

#### Механики
- 3 - удаление камней.
- 4 - создание земляного элемента в случайной точке этих камней + удаление + запись очков.
- 5 - создание элемента молнии посередине + удаление + запись очков.
- Уголок 3x3 - создание водяного элемента в угле + удаление камней + запись очков.

### Элементы

#### Земляной камень
##### Анимации
- Блок со значком земли.
- Взрыв при положительном взаимодействии.

##### Механика
- При перестановке удаляет камни вокруг в радиусе клетки + записывает очки.

#### Молния камень
##### Анимация
- Значек колеблющейся молнии.

##### Механика
- При удалении молния уничтожает всю линию.
- Удаляем все камни по линии перестановки + записывает очки.

#### Водяной камень
##### Анимации
- Значок воды на нем.

##### Механика
- Пуляется водой и уничтожает камни.
- При переставлении уничтожает 4 случайных камня на доске того же цвета, что и камень, с которым его поменяли.

#### Алмаз
##### Вид
- Выглядит как алмаз.

##### Механика
- Не взаимодействоем ни с чем. Только падает вниз.
- При попадании на нижнюю клетку поля падает вниз и пропадает.

# Блоки

## Земляной
### Вид
- Закрытые поля на доске.

### Механика
- Не заполняются ниче, пока не открыты.
- Уничтожаются при комбинации в одной клетке от них.
- При попадании по ним элементов.

## Деревянный
### Вид
- Вокруг камня находится деревяная клетка, а за ним тоже дерево.

### Механика
- Клетка открывается при взаимодейств в одной клетке от него или попадании по нему элемента.
- Подложка камня уничтожается таким же образом.
