# Вне уровня

## Заставка
* Картинка
* Прогресс по загрузке игры (возможно, если будем долго грузиться)
* Текущая версия игры
* Музыка запуска игры

## Навигатор
* Фон текущего эпизода (также фоны прошлых эпизодов при переходе к ним)
* Кнопки для перехода на другие разблокированные эпизоды
* Текущее состояние баллов игрока
  * Количество жизней
  * Количество звезд за текущий эпизод
* Необходимое количество звезд для открытия следующего эпизода
* Настройки
  * Управление музыкой
* Иконки уровней
  * На пройденных уровнях количество звезд
  * На не пройденных другая иконка
* Бонусы между уровнями (как подарки или что-то подобное)


# Уровень

## Старт уровня
* Картинка и прогресс  (возможно, если будем долго грузиться)
* При старте уровня должны предлагаться выбираться бонусы из тех что у игрока есть

## Начальная конфигурация уровня
* Сетка уровня (может быть различная структура: иметь разные формы и дырки внутри)
* Описание направления всех возможных переходов кубиков
  * Могут быть различные варианты
* Изначальное заполнение сетки объектами
  * Расположение камней
  * Расположение элементалей
  * Расположение блоков
* Условие окончания уровня
  * Количество ходов
  * Возможно таймер
  * Возможные условия по устранению блоков\элементалей\камней
* Выпадения
 * Ограничения на выпадения (по цвету камней, элементалей)
 * Вероятности благоприятных выпадений
   * Сделать возможным подкрутку хороших выпадений или увеличения их вероятностей
* Возможные бонусы на уровне за винстрик
  * Добавление элементалей на уровень
  * Добавление времени
  * Добавление ходов
  * Добавление обилок

## Показ рекламы
* Реклама должна показывать по окончании уровня
* Реклама должна показывать на весь экран
* Реклама не должна засчитываться, если человек вышел из приложения

## Игровые объекты

### Камни

#### Виды
- Камни 5-ти различных цветов.

#### Механики
- 3 - удаление камней.
- 4 - создание земляного элемента в случайной точке этих камней + удаление + запись очков.
- 5 - создание элемента молнии посередине + удаление + запись очков.
- Две строки 3x3 - создание водяного элемента в угле + удаление камней + запись очков.
- 6 - создание элемента самоцвета в случайном месте 6-ки
- 7 - очистка всей таблицы (типо это почти невозможно, аналог джекпота)
- 6 + (+2) (когда с 6-ой образуют комбинации другие камни) - удаление строки с этими комбинациями, создание самоцвета

### Элементали

#### Земляной элементаль
##### Анимации
- Блок со значком земли.
- Взрыв при положительном взаимодействии.

##### Механика
- При перестановке удаляет камни вокруг в радиусе клетки + записывает очки.

#### Молния элементаль
##### Анимация
- Значек колеблющейся молнии.

##### Механика
- При удалении молния уничтожает всю линию.
- Удаляем все камни по линии перестановки + записывает очки.

#### Водяной элементаль
##### Анимации
- Значок воды на нем.

##### Механика
- Пуляется водой и уничтожает камни.
- При переставлении уничтожает 5 случайных камней на доске

#### Самоцвет
- При комбинации с камнем удаляет не более пяти случайных камней того же цвета на доске

#### Алмаз
##### Вид
- Выглядит как алмаз.

##### Механика
- Не взаимодействоем ни с чем. Только падает вниз.
- При попадании на нижнюю клетку поля падает вниз и пропадает.

#### Общие механики
- При перестановке элементалей все действуют стандартно, кроме самоцвета, который удаляет камни случайного цвета, которые есть на доске
- Механики элементалей должны учитывать 100% срабатывание. То есть, если камень уничтожит камень №2, то эффект от способности второго камня тоже должен быть
- Каждый камень при уничтожении реализует свой эффек

## Блоки

### Земляной
#### Вид
- Закрытые поля на доске.

#### Механика
- Не заполняются ниче, пока не открыты.
- Уничтожаются при комбинации в одной клетке от них.
- При попадании по ним элементов.

### Деревянный
#### Вид
- Вокруг камня находится деревяная клетка, а за ним тоже дерево.

#### Механика
- Клетка открывается при взаимодействии в одной клетке от него или попадании по нему элемента.
- Подложка камня уничтожается таким же образом.

# Обилки
* Дополнительные способности игрока (расположены снизу)
* Варианты обилок
  * Уничтожение камня\элементаля\блока
  * Увеличение времен
  * Увеличение ходов
  * Удаление строки (как элементаль молнии)
* Откуда берутся
  * Могут накапливаться за уничтожение какого-то количества камней (или других элементов) на уровне
  * За винстрик


* Данные обо всех конфигурациях уровней
  * Сетка
  * Изначальное расположение
  * Будущие выпадения (если они детерминированы)
  * Маршруты движения 
  * Условия завершения уровня
 
* Данные о прохождении уровней
  * Какие уровни пройдены
    * На какое количество звезд
  * Какие уровни не пройдены
 
* Винстрик
  * Базово понимается как прохождения n уровней подряд с первой попытки
  * Может быть дополнен необходимость проходить на 2 или 3 звезды каждый уровень
 
* Механика подсчета очков за уровень
  * Каждой комбинации присваивается свое количество очков, а в конце уровня все суммируется. Также прибавляются очки за дополнительные параметры (общие и зависящие от уровня)
    - 3 - 3 очка
    - 4 - 4 очка
    - 5 - 5 очков
    - Две строки 3x3 - 5 очков
    - 6 - 6 очков
    - 7 - 7 очков
    - 6 + (+2) (когда с 6-ой образуют комбинации другие камни) - 8 очков
    - За каждый оставшийся ход - 5 очков
    - За каждые оставшиеся 5 секунд - 5 очкков

# Вне уровня
* При старте должна показываться заставка
* После заставки должен появляться навигатор уровня
## Заставка
* На заставке должна быть картинка
* На заставке должен быть прогресс по загрузке игры (возмножно, если будем долго грузиться)
* На заставке должна быть указана текущая версия игры
## Навигатор
* В навигаторе должна быть картинка - подложка
* В навигаторе должно отображаться текущее состояние бонусов игрока

# Уровень
## Старт уровня
* При старте уровня должен быть прогресс  (возмножно, если будем долго грузиться)
* При старте уровня должны предлагаться выбираться бонусы из тех что у игрока есть

## Начальная конфигурация уровня
Начальная конфигурация должна включать:
* контур уровня: уровень может иметь сложный внешний контур и дырки в середине
* описание направления перехода кубиков при исчезновении кубиков (каждая позиция известно куда переходит)
* переход может быть в любую несвязанную точку
* набор кубиков (набор цветов кубиков для изначального заполнения сверху)
* расположение специальных кубиков изначальное
