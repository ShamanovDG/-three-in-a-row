# Требования в целом
Количество жизней состоит из двух частей: базовые жизни и бонусные жизни. 
Оба параметра хранятся в [[_Профиль пользователя]] под №4,6.

Базовые жизни должны восстанавливаться по таймеру физического времени, бонусные жизни должны получать по результатам прохождения уровня.

# Хранение
Хранится в [[Конфигурация профиля пользователя]] в настройках №5,6

## Отображение
Оставшися бонусные [[Накопленные жизни|жизни]] и оставшиеся базовые жизни [[Накопленные жизни|жизни]] видны на [[Экран - Навигатор]] общей суммой

Физическое время восстановления последней базовой [[Накопленные жизни|жизни]] испольльзуется для отображения счетчика времени восстановления следующей жизни  на [[Экран - Навигатор]]
