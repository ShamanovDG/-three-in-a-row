### Элементали

| Название | Анимации                                                                                | Механика                                                                                                    |
| -------- | --------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Земляной | - Блок со значком земли.<br>- Взрыв при положительном взаимодействии.                   | - При перестановке удаляет камни вокруг в радиусе клетки + записывает очки.                                 |
| Молния   | - Значек колеблющейся молнии.                                                           | - При удалении молния уничтожает всю линию.<br>- Удаляем все камни по линии перестановки + записывает очки. |
| Водяной  | - Значок воды на нем.                                                                   | - Пуляется водой и уничтожает камни.<br>- При переставлении уничтожает 5 случайных камней на доске          |
| Самоцвет | - При комбинации с камнем удаляет не более пяти случайных камней того же цвета на доске |                                                                                                             |
