## Общее
Дополнительные способности игрока

| Название                                                                | Описание                                                                               |
| ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Удаление объекта                                                        | Удаление одного из объектов на уровне                                                  |
| Удаление строки                                                         | Удаление всех камней в строке, удаление всех элементалей в строке с их срабатыванием   |
| Удаление столбца                                                        | Удаление всех камней в столбце, удаление всех элементалей в столбце с их срабатыванием |
| Перемешивание [[Камни\|камней]] и [[Элементали\|элементалей]] на уровне | Все перемешивается.<br>Надо ли проверять что есть ходы?                                |
| Увеличение времени                                                      |                                                                                        |
| Увеличение ходов                                                        |                                                                                        |
