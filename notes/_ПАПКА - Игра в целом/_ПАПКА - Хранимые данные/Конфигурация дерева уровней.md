
# Дерево уровней
![[_Дерево уровней#Общее]]


## Хранение
Храним как массив уровней. Каждый элемент массива содержит: 
* идентификатор [[_Уровень|уровня]] в [[Конфигурация уровней]]
* ссылка на уровень родителя в дереве
* номер ответвления от родителя (если у родителя несколько потомков, то они нумеруются от 1 и далее) - по умолчанию 1
* условия открытия уровня
	* накопленные [[Звезда|Звезды]] для доступна к уровню
	* требуемые [[Абилка]]
	* пройденные уровни (по умолчанию только родитель)

Рассчитываемый атрибуты при сохранении дерева

| Название              | Описание                                                                      | Алгоритм расчета                                                                                                                                                          |
| --------------------- | ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Номер уровня в дереве | Означает путь к уровню. Указывает все развилки в дереве и сам уровень в конце | Например 12-2.13-1.5 означает<br>12 уровень от корня дерева и второе ответвление от него; в ответвлении 13 элемент и первое ответвление от него; 5 элемент в ответвлении. |
|                       |                                                                               |                                                                                                                                                                           |
