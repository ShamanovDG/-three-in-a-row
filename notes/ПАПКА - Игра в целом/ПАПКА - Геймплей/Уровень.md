
# Уровень в дереве и его доступность
Описание уровне предсталяет из себя ациклический граф-дерево с одним корневым узлом. 
Каждый узел в дереве содержит следующие условия по его открытию:
* Предыдущий узел в дереве
* Признак того, что на узел не попадешь без прохождения предыдущего
* Накопленные [[Звезда|Звезды]] для доступна к уровню
