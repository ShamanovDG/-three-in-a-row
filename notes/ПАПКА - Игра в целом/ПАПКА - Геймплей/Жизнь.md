# Требования в целом
Количество жизней состоит из двух частей: базовые жизни и бонусные жизни. 
Оба параметра хранятся в [[Профиль пользователя]] под №4,6.

Базовые жизни должны восстанавливаться по таймеру физического времени, бонусные жизни должны получать по результатам прохождения уровня.
